## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

## Project setup

```bash
$ npm install
```

Create `example/.env.local` with the Xesar broker connection details. The example loads this file from the example directory:

```dotenv
XS3_HOST=your-broker-host
XS3_PORT=1883
XS3_PROTOCOL=mqtts
XS3_CERT=certs/client.crt
XS3_CA=certs/ca.crt
XS3_KEY=certs/client.key
XS3_CLIENT_ID=your-client-id
XS3_TOKEN=your-session-token
```

`XS3_CERT`, `XS3_CA`, and `XS3_KEY` are filesystem paths; relative paths are resolved from the `example` directory. Keep `.env.local` and the certificate/key files out of version control. `XS3_PORT` must be an integer from 1 to 65535.

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
